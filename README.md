# PRODIGY_DS_04 - Sentiment Analysis

# Task Objective
To analyze sentiment patterns in social media data.

# Dataset
Twitter Sentiment Dataset

# Tools Used
- Python
- Pandas
- Seaborn
- Matplotlib
- WordCloud

# What I Did
- Cleaned dataset and corrected column names
- Analyzed sentiment distribution
- Visualized sentiment by top topics
- Generated word cloud for text data

# Key Insights
- Negative sentiment is slightly higher than positive
- Sentiment varies across topics
- Common words include "game", "love", "play"
